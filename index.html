우편번호 추출기

주소가 적힌 엑셀 파일을 올리면, 주소 열을 자동으로 찾아 우편번호 열을 새로 추가해줍니다. 모든 처리는 이 브라우저 안에서만 이루어지며 파일이 서버로 전송되지 않습니다.

1 주소 검색 API 키

기본 키가 미리 입력되어 있어 바로 업로드하셔도 됩니다. 이 키는 하루 조회량이 여러 사람과 공유되므로, 대량 파일을 자주 처리하신다면 본인 키로 바꿔 쓰시는 걸 권장합니다.
내 키로 직접 발급받기
  1. juso.go.kr 접속
  2. 상단 메뉴 오픈API → 신청하기 (또는 개발자센터 → OpenAPI 연계 등록)
  3. 휴대폰 본인인증으로 로그인/가입
  4. 서비스명 등 간단한 정보 입력 후 신청 → 승인키 즉시 발급
키는 이 브라우저에만 저장되며(localStorage), 외부로 전송되지 않습니다.
